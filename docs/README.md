# Math formulas
1. Общее описание решения

Данный проект предназначен для вычисления геометрических характеристик различных фигур.

Основная задача проекта — предоставить набор функций для вычисления:

площади геометрических фигур;

периметра геометрических фигур.

Проект построен таким образом, чтобы отдельные математические операции были представлены отдельными функциями. Это позволяет повторно использовать функции в разных частях программы и упрощает тестирование и сопровождение проекта.
## Area
>### площади
- Circle: S = πR²
>считаем площадь круга (функция из файла circle.py)

>эта функция принимает r, возвращает значение площади круга с радиусом r

    параметры: 
    (int) r:     радиус круга
    возвращаемое значение: площадь круга 
    пример вызова
    >>>area(3)
    28,274333882219  
- Rectangle: S = a*b
>считаем площадь прямоугольника (функция из файла rectangle.py)

>эта функция принимает a,b возвращает значение площади прямоугольникка со сторонами a и b

    параметры: 
    (float) a:  ширина прямоугольника 
    (float) b: длина прямоугольника
    возвращаемое значение: площадь прямоугольника
    пример вызова
    >>>area(3,4)
    12
- Square: S = a²
>считаем площадь квадрата (функция из файла square.py)

>эта функция принимает a, возвращает значение площади квадрата со стороной a

    параметры: 
    (int) a:     сторона квадрата
    возвращаемое значение: площадь квадрата
    пример вызова
    >>>area(3)
    9  
- Triangle: S = a*h/2
>считаем площадь треугольника (функция из файла triangle.py)

>эта функция принимает a,h возвращает значение площади прямоугольникка со сторонами a и b

    параметры: 
    (float) a: сторона треугольника 
    (float) h: высота треугольника 
    возвращаемое значение: площадь треугольника
    пример вызова
    >>>area(3,4)
    6
## Perimeter
>### периметры
- Circle: P = 2πR
>считаем периметр круга (функция из файла circle.py)

>это функция принимает r, возвращает значение длины окружности с радиусом r 

     параметры: 
    (int) r:     радиус круга
    возвращаемое значение: перметр круга
    пример вызова
    >>>perimetr(3)
    18,8495559214793
- Rectangle: P = 2*(a+b)
>считаем периметр прямоугольника (функция из файла rectangle.py)

>эта функция принимает a,b возвращает значение периметра прямоугольникка со сторонами a и b

    параметры: 
    (float) a:  ширина прямоугольника 
    (float) b: длина прямоугольника
    возвращаемое значение: периметр прямоугольника
    пример вызова
    >>>perimetr(3,4)
    14
- Square: P = 4a
>считаем периметр квадрата (функция из файла square.py)

>эта функция принимает a, возвращает значение периметра квадрата со стороной a

     параметры: 
    (int) a:     сторона квадрата
    возвращаемое значение: перметр квадрата
    пример вызова
    >>>perimetr(3)
    12
- Triangle: P = a+b+c
>считаем периметр треугольника (функция из файла triangle.py)

>эта функция принимает a,h возвращает значение периметра прямоугольникка со стороной a и высотой h 

    параметры: 
    (float) a: сторона треугольника
    (float) b: вторая сторона треугольника
    (float) c: третья сторона треугольника
    возвращаемое значение: периметр треугольника
    пример вызова
    >>>perimetr(3,4,5)
    12
